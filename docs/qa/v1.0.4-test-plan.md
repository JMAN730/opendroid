credential path, so a 1.0.3 install with saved keys is the case most likely to break.

- [ ] Fresh install on clean device, onboarding completes — `E`
- [ ] Upgrade 1.0.3 → 1.0.4 in place with the same signing key, no uninstall prompt — `E`
- [ ] Provider API keys saved under 1.0.3 still decrypt after the legacy crypto removal — `E`
- [ ] Hugging Face token survives the upgrade — `E`
- [ ] If keys fail to decrypt, the app shows a clean re-entry prompt, not a crash loop — `E`
- [ ] Room DB stays at version 7 and opens after upgrade, no destructive fallback — `E`
- [ ] Chat history, memories, and notification history intact after upgrade — `E`
- [ ] Macros recorded pre-upgrade are still listed post-upgrade — `E`
- [ ] Reinstall/downgrade does not corrupt Keystore state — `E`
